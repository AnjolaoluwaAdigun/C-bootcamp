# C# Assignment 3

Console application with solutions to all 10 questions.

## How to Run

Pick a question number from the menu and press Enter.

## Questions

1. Initials Generator
2. Password Checker
3. String Reversal (no built-in methods)
4. Employee Class
5. Book Class
6. Simple Calculator with Memory
7. Browser Back Button (Stack)
8. Hospital Patient Queue (Queue)
9. Student Score Manager (SortedList)
10. Phonebook App (Hashtable)
